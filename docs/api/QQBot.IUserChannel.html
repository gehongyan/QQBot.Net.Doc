SendWakeupMessageAsync(string?, IMarkdown?, FileAttachment?, Embed?, Ark?, IKeyboard?, MessageReference?, RequestOptions?)

向此单聊发送一条互动召回消息。

Task<IUserMessage> SendWakeupMessageAsync(string? content = null, IMarkdown? markdown = null, FileAttachment? attachment = null, Embed? embed = null, Ark? ark = null, IKeyboard? keyboard = null, MessageReference? messageReference = null, RequestOptions? options = null)

Parameters

content string

要发送的消息内容。

markdown IMarkdown

要发送的 Markdown 消息内容。

attachment FileAttachment?

要发送的文件附件。

embed Embed

要发送的嵌入式消息内容。

ark Ark

要发送的模板消息内容。

keyboard IKeyboard

要发送的按钮。

messageReference MessageReference

消息引用，用于回复消息。

options RequestOptions

发送请求时要使用的选项。

Returns

Task<IUserMessage>

一个表示异步发送操作的任务。任务的结果包含所发送消息的可延迟加载的消息对象。

Remarks

此方法仅适用于 QQ 单聊互动召回，不能作为对用户消息或事件的被动回复发送。 QQ 平台在用户主动与机器人互动后的未来 30 天内，按当天、1–3 天、3–7 天、7–30 天四个窗口各允许一条召回消息； SDK 不缓存或预判该额度，平台拒绝时会抛出 HttpException。

TriggerTypingAsync(TimeSpan?, IUserMessage?, RequestOptions?)

显示机器人正在输入的状态。

Task TriggerTypingAsync(TimeSpan? duration = null, IUserMessage? passiveSource = null, RequestOptions? options = null)

Parameters

duration TimeSpan?

输入中状态的持续时间；为 null 时使用 60 秒。非整秒持续时间会向上取整到下一整秒。

passiveSource IUserMessage

可选的被动回复消息来源。

options RequestOptions

发送请求时要使用的选项。

Returns

Task

一个表示异步发送操作的任务。

Remarks

此方法仅适用于 QQ 单聊。未指定持续时间时，状态默认持续 60 秒；有效范围为大于零且不超过 60 秒。 可选地提供触发输入状态的用户消息，以便作为该消息的被动回复发送。
