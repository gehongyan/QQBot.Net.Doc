Escape(string?)

转义字符串，将原始文本中的内嵌格式转义为转义字符。

public static string? Escape(string? text)

Parameters

text string

要转义的文本。

Returns

string

转义后的文本。

Remarks

此方法会将文本中的 &、< 和 > 字符分别转义为 &amp;、&lt; 和 &gt;。 此操作会保留网关或 API 返回的文本内容在用户侧的显示形式。
例如，用户发送用户提及 @someone，网关下传 <@!4937680016579989979>，经过此方法转义的结果为 &lt;@!4937680016579989979&gt;，发送给用户后，用户将看到 <@!4937680016579989979>。
例如，用户发送 <@!4937680016579989979>，网关下传 &lt;@!4937680016579989979&gt;，经过此方法转义的结果为 &amp;lt;@!4937680016579989979&amp;gt;，发送给用户后，用户将看到 &lt;@!4937680016579989979&gt;。

Sanitize(string?, params string[])

转义字符串，安全地转义任何 Markdown 序列。

public static string? Sanitize(string? text, params string[] sensitiveCharacters)

Parameters

text string

要转义的文本。

sensitiveCharacters string[]

要转义的字符。

Returns

string

获取转义后的文本。

Remarks

如果未指定要转移的字符，则将使用默认的转义字符列表。默认的待转义字符包括：
</code>、*、~、`、:、-、]、)、>、#。 此方法会在每个待转义字符前添加一个零宽空格字符（U+200B）。此操作会使内嵌格式提及失效。
例如，用户发送用户提及 @someone，网关下传 <@!4937680016579989979>，经过此方法转义的结果为 <@!4937680016579989979\u200B>，发送给用户后，用户将看到 <@!4937680016579989979>。
例如，用户发送 <@!4937680016579989979>，网关下传 &lt;@!4937680016579989979&gt;，经过此方法转义的结果为 &lt;@!4937680016579989979&\u200Bgt;，发送给用户后，用户将看到 <@!4937680016579989979>。
