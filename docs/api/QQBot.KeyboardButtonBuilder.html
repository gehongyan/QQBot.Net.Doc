Properties

Action

获取或设置此按钮的动作类型。

public ButtonAction? Action { get; set; }

Property Value

ButtonAction?

Remarks

未设置时，将根据以下规则尝试推断：

  • 当 IsCommandReply、IsCommandAutoSend 或 ActionAnchor 任一属性被设置时，将使用 Command。
  • 当 Data 不为 null 时，将调用 TryCreate(string, UriKind, out Uri) 方法，第一个参数为 Data 属性的值，第二个参数为 Absolute，若返回 true，则使用 Jump。
  • 其他情况下，使用 Callback。
