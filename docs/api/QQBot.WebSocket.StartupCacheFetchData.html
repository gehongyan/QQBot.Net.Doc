Enum StartupCacheFetchData

Namespace
QQBot.WebSocket
Assembly
QQBot.Net.WebSocket.dll

表示基于网关的客户端在启动时所加载的除频道列表外的其它数据。

[Flags]
public enum StartupCacheFetchData

Fields

All = AllPublicDomain | GuildUsers

加载所有基础数据。

AllPublicDomain = Roles | Channels

加载所有公域机器人可以加载的数据。

Channels = 2

加载子频道列表。

子频道列表会在 Bot 启动时优先下载，若 StartupCacheFetchMode 设置为 Synchronous， Ready 事件引发时子频道列表应已经下载完成。 调用 UpdateAsync(RequestOptions?) 时也会更新角色列表。

GuildUsers = 4

加载频道用户列表。

子频道列表会在 Bot 启动时推迟下载，即便 StartupCacheFetchMode 设置为 Synchronous， Ready 事件引发时也无法保证频道用户列表下载完成。 调用 UpdateAsync(RequestOptions?) 时不会更新频道用户列表。 要获取频道用户列表，需要调用 DownloadUsersAsync(RequestOptions?)。

None = 0

不在启动时加载除频道列表外的其它数据。

Roles = 1

加载频道角色列表。

角色列表会在 Bot 启动时优先下载，若 StartupCacheFetchMode 设置为 Synchronous， Ready 事件引发时角色列表应已经下载完成。 调用 UpdateAsync(RequestOptions?) 时也会更新角色列表。
